# ✅ БЫСТРОЕ РЕШЕНИЕ ПРОБЛЕМЫ С /ru/

## 🎯 ЧТО БЫЛО СДЕЛАНО

### Проблема
При поиске "tamexgroup" в Google ссылка переадресовывается на `https://tamexgroup.com/ru/`, но этот роут **НЕ СУЩЕСТВУЕТ** в приложении.

### Решение
Я исправил проблему **СЕЙЧАС**:

#### 1. ✅ Удалены неработающие hreflang ссылки из `index.html`
   - Закомментированы ссылки на несуществующие `/ru/`, `/uz/`, `/en/`
   - Это предотвращает появление битых ссылок для поисковых систем

#### 2. ✅ Добавлены редиректы в `netlify.toml`
   - Все запросы к `/ru/*`, `/uz/*`, `/en/*` теперь редиректятся на главную `/`
   - Используется статус 301 (постоянный редирект) для правильной индексации

## 📋 ПОШАГОВЫЙ ПЛАН НАСТРОЙКИ GOOGLE SEARCH CONSOLE

### ШАГ 1: Добавить сайт в Search Console

1. Перейдите на: https://search.google.com/search-console
2. Нажмите **"Добавить ресурс"**
3. Выберите тип: **"Префикс URL"**
4. Введите: `https://tamexgroup.com`
5. Нажмите **"Продолжить"**

### ШАГ 2: Проверка права владения

Google предложит несколько методов проверки:

**МЕТОД 1: HTML-тег (самый простой)**

1. Google покажет код для вставки
2. Откройте файл `index.html`
3. Найдите тег `<head>`
4. Добавьте перед `</head>`:
```html
<meta name="google-site-verification" content="ВАШ_КОД_ЗДЕСЬ" />
```
5. Сохраните файл
6. Задеплойте изменения на Netlify
7. Вернитесь в Search Console и нажмите **"Проверить"**

**МЕТОД 2: HTML-файл**
- Скачайте файл от Google
- Загрузите его в корень вашего сайта
- Проверьте в Search Console

### ШАГ 3: Отправка sitemap

1. В Search Console выберите ваш сайт
2. Откройте меню **"Sitemaps"** (Карты сайта)
3. В поле "Добавить новую карту сайта" введите:
   ```
   https://tamexgroup.com/sitemap.xml
   ```
4. Нажмите **"Отправить"**

Также отправьте дополнительные карты:
- `https://tamexgroup.com/sitemap-main.xml`
- `https://tamexgroup.com/sitemap-products.xml`
- `https://tamexgroup.com/sitemap-images.xml`

### ШАГ 4: Запросить удаление неправильной страницы

1. В Search Console откройте **"Удаление URL"**
2. Нажмите **"Новая заявка"**
3. Выберите **"Временно скрыть и запретить отображение в поиске"**
4. Введите URL: `https://tamexgroup.com/ru/`
5. Нажмите **"Отправить заявку"**
6. Google удалит эту ссылку из поиска через 1-2 недели

### ШАГ 5: Запросить переиндексацию главной страницы

1. В Search Console используйте инструмент **"Проверка URL"**
2. Введите: `https://tamexgroup.com`
3. Нажмите **"Запросить индексирование"**
4. Google переиндексирует вашу главную страницу
