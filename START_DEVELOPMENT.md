# Инструкция по запуску проекта в режиме разработки

## 🚀 Быстрый старт

### Шаг 1: Установите зависимости

```bash
npm install
```

### Шаг 2: Настройте Telegram бота

1. Создайте `.env` файл в корне проекта:
   ```bash
   cp env.example .env
   ```

2. Откройте `.env` и заполните:
   ```env
   TELEGRAM_BOT_TOKEN=ваш_токен_от_BotFather
   TELEGRAM_CHAT_ID=ваш_chat_id
   PORT=3001
   FRONTEND_URL=*
   VITE_API_URL=/api/contact
   ```

   **Как получить токен и Chat ID:**
   - Токен: Найдите @BotFather в Telegram → `/newbot` → скопируйте токен
   - Chat ID: Для личного чата используйте @userinfobot, для группы - создайте группу и используйте `getUpdates`

### Шаг 3: Запустите серверы

**Терминал 1 - Backend API:**
```bash
npm run server
```

Вы должны увидеть:
```
🚀 Сервер запущен на порту 3001
📡 API endpoint: http://localhost:3001/api/contact
💚 Health check: http://localhost:3001/api/health
✅ Telegram бот настроен
```

**Терминал 2 - Frontend:**
```bash
npm run dev
```

Vite запустится на `http://localhost:5173` (или другом порту)

### Шаг 4: Проверьте работу

1. Откройте `http://localhost:5173` в браузере
2. Заполните форму контактов или используйте виртуального ассистента
3. Отправьте форму
4. Проверьте Telegram - должно прийти сообщение! ✅

## 🔧 Устранение проблем

### Ошибка: `Failed to load resource: net::ERR_CONNECTION_REFUSED`

**Проблема:** Backend сервер не запущен

**Решение:** Убедитесь, что вы запустили `npm run server` в отдельном терминале

### Ошибка: `404 (Not Found)` на `/api/contact`

**Проблема:** Backend не запущен или прокси не настроен

**Решение:** 
1. Проверьте, что backend запущен на порту 3001
2. Проверьте файл `vite.config.ts` - должен быть настроен proxy

### Ошибка: `Unexpected end of JSON input`

**Проблема:** Сервер не отвечает или возвращает пустой ответ

**Решение:**
1. Проверьте логи backend сервера
2. Убедитесь, что `.env` файл настроен правильно
3. Проверьте health endpoint: `curl http://localhost:3001/api/health`

### Ошибка: `Telegram API error`

**Проблема:** Неправильный токен или Chat ID

**Решение:**
1. Проверьте токен в `.env` - должен начинаться с числа и содержать двоеточие
2. Проверьте Chat ID - для группы должен начинаться с минуса
3. Убедитесь, что бот добавлен в группу (если используется группа)

## 📝 Важные замечания

- **Всегда запускайте backend перед фронтендом** в режиме разработки
- Vite автоматически проксирует запросы `/api/*` на `http://localhost:3001`
- В production режиме настройте `VITE_API_URL` на полный URL вашего API сервера

## 🔍 Проверка работы API

Откройте в браузере или через curl:

```bash
# Health check
curl http://localhost:3001/api/health

# Должен вернуть:
# {"status":"ok","timestamp":"...","service":"Tamex Contact API"}
```

Если всё правильно, то форма должна работать без ошибок!
