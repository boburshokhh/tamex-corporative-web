# Инструкция по настройке Google Search Console для tamexgroup.com

## 📋 Шаг 1: Добавление и подтверждение сайта

### 1.1 Добавить свойство сайта

1. Перейдите на [Google Search Console](https://search.google.com/search-console)
2. Нажмите **"Добавить ресурс"** (Add property)
3. Выберите **"Префикс URL"** (URL prefix)
4. Введите: `https://tamexgroup.com`
5. Нажмите **"Продолжить"**

### 1.2 Подтверждение права собственности

**Рекомендуемый метод: HTML-тег**

1. Google предоставит HTML-тег для подтверждения
2. Добавьте этот тег в раздел `<head>` файла `index.html`
3. Разместите тег **после** строки 4 (`<meta charset="UTF-8" />`), **до** закрывающего `</head>`
4. Деплойте изменения
5. Вернитесь в Search Console и нажмите **"Подтвердить"**

**Альтернативные методы:**
- Загрузка HTML-файла (создайте файл с именем, указанным Google, в папке `public/`)
- DNS-запись (если есть доступ к DNS)
- Google Analytics (если подключен)

---

## 🗺️ Шаг 2: Настройка Sitemap

### 2.1 Отправка основного Sitemap

1. В левом меню выберите **"Sitemaps"** (Карты сайта)
2. В поле **"Добавить новую карту сайта"** введите:
   ```
   https://tamexgroup.com/sitemap.xml
   ```
3. Нажмите **"Отправить"**

### 2.2 Отправка дополнительных Sitemap

Отправьте также отдельные карты сайта (опционально, но рекомендуется):

```
https://tamexgroup.com/sitemap-main.xml
https://tamexgroup.com/sitemap-products.xml
https://tamexgroup.com/sitemap-blog.xml
https://tamexgroup.com/sitemap-images.xml
```

**Примечание:** После отправки Google может занять от нескольких часов до нескольких дней для обработки карт сайта.

---

## 🚫 Шаг 3: Удаление неправильного URL /ru/

### 3.1 Временное удаление через инструмент удаления URL

1. В левом меню выберите **"Удаление"** (Removals)
2. Нажмите **"Создать запрос на удаление"** (New removal request)
3. Введите URL для удаления:
   ```
   https://tamexgroup.com/ru/
   ```
4. Выберите тип: **"Временно удалить из результатов поиска"**
5. Нажмите **"Отправить запрос"**

**Важно:** Это временная мера. После того как Google переиндексирует сайт с редиректами, запись исчезнет автоматически.

### 3.2 Удаление через инструмент проверки URL

1. В верхней строке поиска введите:
   ```
   https://tamexgroup.com/ru/
   ```
2. Нажмите **"Проверить URL"** (Inspect URL)
3. Дождитесь завершения проверки
4. Нажмите **"Запросить удаление"** (Request removal)
5. Выберите причину: **"URL больше не существует"** или **"Страница возвращает ошибку"**
6. Подтвердите запрос

## 🔍 Шаг 4: Настройка параметров сканирования

### 4.1 Настройка предпочтительного домена

1. В левом меню выберите **"Настройки"** (Settings)
2. Перейдите в раздел **"Параметры"** (Crawling)
3. Найдите **"Предпочитаемый домен"** (Preferred domain)
4. Выберите: **"Отображать URLs как `tamexgroup.com`"** (или www-версию, если используете)
5. Нажмите **"Сохранить"**

### 4.2 Настройка частоты сканирования

1. В том же разделе найдите **"Частота сканирования"** (Crawl rate)
2. Выберите: **"Разрешить Google оптимизировать частоту сканирования"** (рекомендуется)
3. Или установите вручную: **"Ограничить частоту сканирования"** и выберите скорость

---

## 📊 Шаг 5: Мониторинг и исправление ошибок

### 5.1 Проверка покрытия индексированием

1. В левом меню выберите **"Покрытие"** (Coverage)
2. Проверьте:
   - **Валидные страницы** - должны отображать основные страницы сайта
   - **Исключенные страницы** - проверьте, нет ли там важных страниц
   - **Ошибки** - должны быть исправлены

### 5.2 Проверка валидных страниц

Убедитесь, что отображаются:
- ✅ `https://tamexgroup.com/` (главная)
- ✅ `https://tamexgroup.com/catalog` (каталог)
- ❌ `https://tamexgroup.com/ru/` - НЕ должно быть здесь

### 5.3 Исправление ошибок (если есть)

Если видите ошибки типа:
- **"404 - страница не найдена"** для `/ru/` - это нормально, они будут автоматически исключены
- **"Робот заблокирован"** - проверьте `robots.txt`
- **"Канонический URL указывает на другую страницу"** - проверьте настройки canonical

## 🔄 Шаг 6: Запрос индексирования основных страниц

### 6.1 Индексирование главной страницы

1. В верхней строке поиска введите:
   ```
   https://tamexgroup.com/
   ```
2. Нажмите **"Проверить URL"** (Inspect URL)
3. Дождитесь завершения проверки
4. Если страница еще не проиндексирована, нажмите **"Запросить индексирование"** (Request indexing)
5. Дождитесь подтверждения

### 6.2 Индексирование страницы каталога

Повторите те же шаги для:
```
https://tamexgroup.com/catalog
```

## ⚙️ Шаг 7: Дополнительные настройки

### 7.1 Настройка параметров URL

1. В левом меню выберите **"Параметры URL"** (URL Parameters)
2. Если используете UTM-метки, добавьте их:
   - Параметр: `utm_source`, `utm_medium`, `utm_campaign`
   - Настройка: **"Не индексировать URL с этим параметром"**

### 7.2 Настройка безопасности

1. В левом меню выберите **"Безопасность и действия нарушений"** (Security & Manual Actions)
2. Проверьте наличие предупреждений
3. Если есть предупреждения, исправьте их согласно инструкциям Google

## 📈 Шаг 8: Мониторинг производительности

### 8.1 Просмотр данных о производительности

1. В левом меню выберите **"Производительность"** (Performance)
2. Проверьте:
   - **Клики** (Clicks)
   - **Показы** (Impressions)
   - **CTR** (Click-through rate)
   - **Средняя позиция** (Average position)

### 8.2 Фильтрация по URL

Чтобы убедиться, что `/ru/` не появляется:
1. В разделе "Производительность" нажмите **"Новый фильтр"**
2. Выберите **"Страница"**
3. Введите `site:tamexgroup.com/ru/`
4. Если результатов нет - отлично! Если есть - это старые данные, они исчезнут со временем

## 📝 Важные примечания

### О редиректах /ru/, /uz/, /en/

✅ **Что мы настроили:**
- Редирект 301 в файле `_redirects`
- Запрет в `robots.txt`
- Правильные canonical URL во всех компонентах

⏳ **Что нужно помнить:**
- Удаление из индекса может занять **2-4 недели**
- Google будет постепенно переиндексировать сайт с учетом новых настроек
- Редирект 301 автоматически передаст "вес" страницы на главную

### О sitemap

- Обновляйте `lastmod` даты в sitemap при изменении контента
- После добавления новых страниц переотправьте sitemap (или подождите автоматического обновления)

### О canonical URL

- Все страницы должны иметь правильный canonical URL
- Canonical должен указывать на основную версию без `/ru/`, `/uz/`, `/en/`
- Проверить можно через инструмент "Проверка URL"

## 🆘 Решение проблем

### Проблема: URL /ru/ все еще появляется в поиске

**Решение:**
1. Убедитесь, что редирект 301 работает (проверьте через браузер)
2. Повторно запросите удаление в Search Console
3. Подождите 2-4 недели для обновления индекса

### Проблема: Sitemap не обрабатывается

**Решение:**
1. Проверьте доступность: откройте `https://tamexgroup.com/sitemap.xml` в браузере
2. Убедитесь, что формат XML корректен
3. Проверьте, что sitemap доступен для Googlebot (не заблокирован в robots.txt)

### Проблема: Страницы не индексируются

**Решение:**
1. Проверьте robots.txt - не заблокирована ли страница
2. Проверьте мета-теги `noindex` (если есть)
3. Запросите индексирование через инструмент "Проверка URL"
4. Убедитесь, что на странице есть ссылки с других страниц сайта
