# 🚀 Быстрый старт: Google Search Console для tamexgroup.com

## ✅ Чек-лист действий (выполнить по порядку)

### 1️⃣ Добавить и подтвердить сайт
- [ ] Перейти на [search.google.com/search-console](https://search.google.com/search-console)
- [ ] Добавить ресурс: `https://tamexgroup.com` (префикс URL)
- [ ] Подтвердить через HTML-тег в `index.html` (в `<head>`)
- [ ] Деплой изменений и подтвердить в Console

### 2️⃣ Отправить Sitemap
- [ ] Меню → **Sitemaps** → Отправить: `https://tamexgroup.com/sitemap.xml`
- [ ] Дождаться статуса "Успешно" (может занять до 24 часов)

### 3️⃣ Удалить неправильный URL /ru/
- [ ] Меню → **Удаление** → Создать запрос на удаление
- [ ] URL: `https://tamexgroup.com/ru/`
- [ ] Тип: Временно удалить
- [ ] ИЛИ через "Проверка URL" → "Запросить удаление"

### 4️⃣ Запросить индексирование правильных страниц
- [ ] Инструмент "Проверка URL" → `https://tamexgroup.com/` → Запросить индексирование
- [ ] Инструмент "Проверка URL" → `https://tamexgroup.com/catalog` → Запросить индексирование

### 5️⃣ Настроить параметры
- [ ] Настройки → Параметры → Предпочитаемый домен: `tamexgroup.com`
- [ ] Частота сканирования: Разрешить Google оптимизировать

### 6️⃣ Проверить результаты
- [ ] Покрытие → Убедиться, что `/ru/` отсутствует
- [ ] Производительность → Проверить основные запросы
- [ ] Ошибки → Исправить критические проблемы

## 📝 Краткие команды для проверки

### Проверка редиректа /ru/
```bash
curl -I https://tamexgroup.com/ru/
# Должен вернуть: HTTP/1.1 301 Moved Permanently
```

### Проверка canonical URL
Откройте страницу → View Source → найти `<link rel="canonical"`

Должно быть: `https://tamexgroup.com/` (без /ru/)
