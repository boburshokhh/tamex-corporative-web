# Настройка переменных окружения для фронтенда

## ⚠️ Важно для Vite

В Vite **все переменные окружения для фронтенда** должны начинаться с префикса `VITE_`, иначе они не будут доступны в клиентском коде.

## 📝 Создание файла .env

1. Создайте файл `.env` в **корне проекта** (там же, где `package.json`)

2. Добавьте следующие переменные **с префиксом VITE_**:

```env
VITE_TELEGRAM_BOT_TOKEN=ваш_токен_от_BotFather
VITE_TELEGRAM_CHAT_ID=ваш_chat_id
```

### Пример:

```env
VITE_TELEGRAM_BOT_TOKEN=1234567890:ABCdefGHIjklMNOpqrsTUVwxyz
VITE_TELEGRAM_CHAT_ID=123456789
```

Или для группы:
```env
VITE_TELEGRAM_BOT_TOKEN=1234567890:ABCdefGHIjklMNOpqrsTUVwxyz
VITE_TELEGRAM_CHAT_ID=-1001234567890
```

## 🔄 После создания/изменения .env

**ОБЯЗАТЕЛЬНО перезапустите dev сервер:**

1. Остановите `npm run dev` (Ctrl+C)
2. Запустите снова: `npm run dev`

Vite загружает переменные окружения только при старте, поэтому изменения в `.env` требуют перезапуска.

## ✅ Проверка

После перезапуска вы можете проверить в консоли браузера (F12):

```javascript
console.log(import.meta.env.VITE_TELEGRAM_BOT_TOKEN)
// Должен показать ваш токен (безопасно, так как это клиентский код)
```

## 🔒 Безопасность

⚠️ **Важно понимать:** Токен Telegram бота будет виден в скомпилированном JavaScript коде!

Это означает, что любой пользователь сможет увидеть токен в DevTools. Для продакшена рекомендуется:
- Использовать backend сервер
- Или ограничить права бота (разрешить отправку только в конкретный чат)
- Или использовать другой метод аутентификации

## 📋 Получение токена и Chat ID

### Токен:
1. Найдите @BotFather в Telegram
2. Отправьте `/newbot`
3. Следуйте инструкциям
4. Скопируйте токен

### Chat ID (личный чат):
1. Начните диалог с вашим ботом
2. Найдите @userinfobot
3. Скопируйте ваш User ID

### Chat ID (группа):
1. Создайте группу
2. Добавьте бота в группу
3. Отправьте сообщение в группу
4. Откройте: `https://api.telegram.org/bot<ВАШ_ТОКЕН>/getUpdates`
5. Найдите `"chat":{"id":-100...}` - это Chat ID группы (с минусом!)
