## 🎯 ПЛАН ДЕЙСТВИЙ В GOOGLE SEARCH CONSOLE

### ШАГ 1: Удалить сломанные страницы из индекса

1. Откройте Google Search Console: https://search.google.com/search-console
2. Перейдите в **"Покрытие"** → **"Исключено"**
3. Найдите страницы со статусом **"Страница с переадресацией"** и **"Не найдено (404)"**
4. Нажмите на каждую ссылку
5. Используйте **"Проверка URL"** → **"Удаление URL"** → **"Временно скрыть"**

**Список страниц для удаления:**
- `https://tamexgroup.com/uslugi/postavka-pod-klyuch/`
- `https://tamexgroup.com/uslugi/`
- `https://tamexgroup.com/kontakty/`
- `https://tamexgroup.com/tendery/`
- `https://tamexgroup.com/o-kompanii/`
- Все ссылки с `/katalog/` (старый путь)

### ШАГ 2: Запросить переиндексацию правильных страниц

1. Используйте **"Проверка URL"**
2. Введите каждый URL:
   - `https://tamexgroup.com/`
   - `https://tamexgroup.com/catalog`
3. Нажмите **"Запросить индексирование"**

### ШАГ 3: Обновить sitemap

1. Перейдите в **"Sitemaps"**
2. Удалите старую карту сайта (если она устарела)
3. Отправьте новую:
   ```
   https://tamexgroup.com/sitemap.xml
   ```

### ШАГ 4: Проверить canonical теги

1. Откройте **"Покрытие"** → **"Вариант страницы с тегом canonical"**
2. Проверьте каждую страницу
3. Убедитесь, что canonical указывает на правильный URL

**Правильная настройка:**
```html
<link rel="canonical" href="https://tamexgroup.com/" />
```

## 🔍 ДЕТАЛЬНЫЙ РАЗБОР ПРОБЛЕМ

### Проблема 1: "Вариант страницы с тегом canonical" (13 страниц)

**Причина:** У некоторых страниц есть canonical тег, указывающий на другую страницу.

**Решение:**
- Проверьте все эти страницы в Search Console
- Убедитесь, что canonical указывает на себя
- Если canonical указывает на главную → это правильно для дублированного контента

### Проблема 2: "Страница с переадресацией" (2 страницы)

**Причина:** Страницы редиректятся на другие URL.

**Решение:**
- Определите, на какой URL они редиректятся
- Если редирект правильный (например, `/katalog/` → `/catalog`) → оставьте как есть
- Если редирект неправильный → исправьте в netlify.toml

### Проблема 3: "Индексирование запрещено noindex" (1 страница)

**Причина:** На странице есть тег `<meta name="robots" content="noindex">`.

**Решение:**
- Найдите эту страницу
- Удалите тег noindex
- Запросите переиндексацию

### Проблема 4: "Не найдено (404)" (1 страница)

**Причина:** Страница удалена или никогда не существовала.

**Решение:**
- URL уже удален из sitemap
- Запросите удаление в Search Console
- Подождите 1-2 недели

### Проблема 5: "Обнаружена, не проиндексирована" (19 страниц)

**Причина:** Google нашел страницы, но еще не успел их проиндексировать.

**Решение:**
- Запросите индексирование через "Проверка URL"
- Обновите sitemap
- Подождите 1-4 недели
